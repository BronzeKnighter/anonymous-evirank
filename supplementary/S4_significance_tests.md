# S4. Statistical Significance Tests

We use two-sided paired query-level permutation tests over per-query metric
values. For each comparison, the null distribution is generated by 10,000
random sign flips of paired differences with seed 42. Significance is assessed
at `p < 0.05` without claiming significance for non-significant differences.

Against the strongest fully comparable baseline for each metric, EviRank is
significant on all three primary KDD metrics and on SIGIR NDCG@10 and Soft
MAP@10. NeurIPS and SciRepEval differences are competitive but not significant.

Exact means, deltas, p-values, and query counts are in
[`significance_tests.csv`](significance_tests.csv).

Given a CSV with paired `evirank` and `baseline` per-query values, reproduce a
test with:

```bash
python tools/paired_permutation_test.py per_query.csv
```
